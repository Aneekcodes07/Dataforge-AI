# DataForge AI — Roadmap

> 6-phase delivery plan. Each phase delivers a usable, shippable increment.

---

## Phase 1: Foundation & Core UI ✅
**Status: Complete**
- Project scaffolding (Vite + React + TS)
- Design system (TailwindCSS v4, glassmorphism, animations)
- Navigation shell (sidebar, navbar)
- Landing page, Auth pages, Dashboard
- Backend skeleton (FastAPI)
- Project memory docs

---

## Phase 2: Extraction Workspace & Agent Network 🔲
**Status: Not Started**
- Extraction page (URL, PDF, CSV, API, Image upload)
- Agent Network visualization (canvas-based, animated nodes)
- Backend extraction engine (web scraper, PDF extractor)
- AI agents (OCR, Extractor, Schema)
- WebSocket for real-time agent status

---

## Phase 3: Data Cleaning & Dataset Explorer 🔲
**Status: Not Started**
- Dataset Explorer (TanStack Table, inline editing)
- Cleaning operations (missing values, duplicates, types)
- Column statistics and data type badges
- Backend cleaning engine (Pandas-based)

---

## Phase 4: EDA Dashboard & ML Recommendations 🔲
**Status: Not Started**
- EDA Dashboard (Recharts visualizations)
- Data quality scoring
- Correlation matrix, distributions, outlier detection
- ML model recommendations
- Feature importance analysis

---

## Phase 5: Dataset Copilot & Export Center 🔲
**Status: Not Started**
- ChatGPT-style Copilot for data conversations
- LLM integration (OpenAI/Anthropic)
- Export Center (CSV, JSON, XLSX, Parquet)
- Column/row selection for partial export

---

## Phase 6: Team, History, Settings & Polish 🔲
**Status: Not Started**
- Team management (invite, roles)
- Version history and diff viewer
- Settings (profile, API keys, theme)
- Light mode toggle
- Performance optimization
- Cross-browser testing
